# 架構說明

## 產品概覽

Master Dog 是一個本地 Codex Skill，由行為指令、界面元數據和按需加載的 Markdown 知識庫組成。倉庫不包含服務器、數據庫、前端應用、賬號系統或遙測。

## 組件

| 組件 | 路徑 | 職責 |
| --- | --- | --- |
| 行為內核 | `SKILL.md` | 定義觸發場景、首次建檔、分析工作流、輸出格式和安全邊界 |
| 界面元數據 | `agents/openai.yaml` | 定義顯示名稱、簡介和默認提示詞 |
| 核心知識 | `references/knowledge/` | 提供關係科學、人格、法律、社會、人文、哲學、婚姻與性學資料 |
| 實用策略 | `references/practical/` | 提供溝通、情緒價值、拒絕、衝突、主動權和話術材料 |
| 驗證器 | `scripts/validate_skill.py` | 檢查結構、元數據、必需文件、最低數量、上下文預算、運行時邊界、斷鏈和場景覆蓋 |
| 項目文檔 | `documentation/` | 記錄產品意圖、運行流程、權限、自動化與測試邊界 |

## 運行方式

Codex 根據 Skill 描述決定是否加載 `SKILL.md`。被調用後，代理在當前任務上下文中執行首次建檔或沿用已有檔案，再按情境讀取一到數份參考文檔。最終輸出是建議、理由、話術、觀察窗口和停止條件；Skill 本身不直接向第三方發送消息，也不修改外部系統。

`SKILL.md` 只保留核心流程、路由和安全邊界，默認按問題讀取 1–3 份參考。項目文檔、測試和原始研究不屬於運行時安裝白名單；運行時只同步 `SKILL.md`、`agents/`、`references/`、`scripts/` 以及存在時的 `assets/`。

倉庫運行 `python3 scripts/validate_skill.py` 校驗項目與運行內容；白名單安裝副本運行 `python3 scripts/validate_skill.py --runtime`，不要求項目文檔和測試存在。

## 信任邊界

1. **用戶 → Codex**：用戶可能提供高度敏感的關係、健康、性、財務和家庭信息。
2. **Skill 指令 → 模型推理**：`SKILL.md` 是行為引導，不是不可繞過的程序級強制器。
3. **參考文檔 → 模型上下文**：知識文件可能過時或存在錯誤，不能視為實時法律、醫療或危機數據庫。
4. **模型建議 → 現實行動**：用戶決定是否發送消息或採取行動；Skill 不自動執行這些副作用。
5. **Codex 工具 → 外部系統**：本 Skill 不聲明或要求任何外部工具。若宿主環境另行啟用工具，權限由宿主和用戶批准機制負責。

## 已知風險與假設

- 首次檔案只在當前任務上下文中可用，不能保證跨任務持久化。
- 模型可能將推測寫得過於肯定，必須依賴“事實／推測／未知”流程降低風險。
- 法律和社會數據具有時效性，引用前需要複核日期與地區。
- 性別、性取向和MBTI標籤可能誘發刻板推斷，行為內核明確要求用實際行為校正。
- 提示詞安全邊界不是程序級安全控制；高風險使用仍依賴宿主模型政策。

## 不適用的系統文檔

- 無郵件發送，因此無 `emails.md`。
- 無定時或後臺任務，因此無 `cron.md`。
- 無公開Web路由或SEO表面，因此無 `seo.md`。
