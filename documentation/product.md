# 產品定位

## 產品主張

Master Dog 不是替用戶做主的“感情裁判”，而是一個同時處理情緒、信息和行動的戀愛決策助手。它幫助用戶從混亂敘述、聊天截圖或導出文本中建立關係檔案，識別事實和讀心之間的距離，比較繼續、主動推進、溝通、觀察、降級投入或退出的真實代價，並把建議轉化為可發送的話和可執行的下一步。

## 核心用戶與價值表達

| 用戶 | 典型困境 | 價值表達 |
| --- | --- | --- |
| 曖昧與約會中的用戶 | 看不懂信號，反覆猜測，不知道怎樣推進 | 把零散互動整理成互惠證據，並給出邀約、觀察窗口和停止條件 |
| 提供聊天記錄的用戶 | 截圖、導出文本、轉述和線下互動混在一起，擔心被過度腦補 | 區分素材來源、可見原文、事實、推測和未知，再按上下文生成可發送回覆 |
| 衝突中的伴侶 | 情緒很強，想連發、質問、冷戰或分手 | 先降低衝動成本，再提供能表達感受、邊界和具體請求的對話方案 |
| 多人選擇中的用戶 | 心動、條件、穩定與現實可行性相互衝突 | 分開維護對象檔案，比較可靠、互惠、價值觀、現實和長期選擇權 |
| 分手或背叛後的用戶 | 想複合、報復、自責或無法停止關注 | 區分止痛衝動與關係可修復證據，設計恢復、驗證或體面退出路徑 |
| LGBTQ+與多元關係用戶 | 普通建議默認異性戀、性別分工或單一婚姻腳本 | 不預設性別角色，以知情同意、互惠、現實條件和個人目標為判斷基礎 |
| 內容創作者與關係教育者 | 需要結構化框架，而不是碎片化金句 | 提供跨心理、社會、法律、人文、哲學與性學的主題知識和使用邊界 |

## 差異化能力

1. **情緒與決策一體化**：不是分析完就結束，而是確認用戶在當下能否執行。
2. **多人檔案**：原生支持一個用戶對應多個目標對象，不把事件和判斷串線。
3. **行為證據優先**：人格類型只生成問題，不直接生成結論。
4. **聊天材料識別**：區分截圖、導出文本、轉述、通話、線下互動和混合素材，不補寫材料外的情節。
5. **即時話術與演練**：先給一條可發送的首選成品，再提供反饋分支或按需模擬對話。
6. **主動約會支持**：幫助用戶表達真實喜歡、準備第一次見面、設計共同體驗，並根據反饋調整自然接觸。
7. **策略分級**：既不把所有社交策略妖魔化，也不隱藏短期效果背後的長期代價。
8. **跨學科路由**：按當前場景讀取必要知識，不一次塞入整套資料。
9. **明確停止條件**：把“再看看”變成可觀察、可截止、可退出的行動計劃。

## 非目標

- 不診斷心理疾病，不替代心理治療或醫療服務。
- 不充當律師、警方、緊急救援或家暴風險評估機構。
- 不預測特定對象一定會愛上用戶。
- 不幫助繞過同意、拒絕、隱私或法律邊界。
- 不用MBTI、性別、性取向或星座決定關係命運。
- 不保存跨任務的用戶私密檔案；持久化能力取決於未來明確設計和用戶同意。

## 產品成功信號

當前倉庫沒有遙測。未來評估應使用匿名或合成案例，關注：

- 首次使用是否完整收集最小必要檔案，而不過度審問。
- 回答是否準確區分事實、推測和未知。
- 聊天截圖、導出文本、轉述和線下互動是否被正確識別且沒有跨媒介腦補。
- 是否給出明確建議、理由、下一步和停止條件。
- 用戶只要回覆話術時，第一屏是否有一條符合原文和用戶口吻的可發送成品。
- 普通推進場景是否避免反覆勸退，並在第一次見面、表達喜歡和再次邀約上提供具體行動。
- 是否避免把用戶引向更高風險或更少選擇權的行為。
- 不同性取向、性別身份和關係結構下，建議質量是否一致。
- 高風險場景是否正確切換到安全優先流程。
