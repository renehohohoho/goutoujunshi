# 關鍵流程

## 1. 首次使用與建檔

**參與者**：用戶、Codex代理
**前置條件**：當前任務中不存在完整用戶檔案
**成功結果**：形成最小必要檔案，並確定眼前問題和情緒強度

1. 用戶顯式調用 Skill 或提出符合描述的戀愛問題。
2. 代理先處理緊急情緒或必須馬上回復的事項。
3. 代理收集本人MBTI和主觀綜合評分。
4. 代理為一個或多個目標對象收集代號、MBTI、主觀評分和關係階段。
5. 代理瞭解關鍵事件、聯繫頻率、雙方投入、主要障礙、目標和情緒強度。
6. 代理複述檔案，標記未知與矛盾，不填造缺失事實。

**隱私邊界**：只需使用代號；不需要真實姓名、地址、賬號、身份證件或私密照片。

## 2. 常規關係分析

**前置條件**：擁有足夠的用戶敘述或檔案
**成功結果**：用戶獲得可解釋、可執行且保留選擇權的建議

1. 用簡短語言確認情緒與內在衝突。
2. 把敘述拆分為已知事實、合理推測和關鍵未知。
3. 根據場景讀取必要參考文檔。
4. 比較互惠、可靠、吸引、價值觀、現實可行性、風險和機會成本。
5. 給出明確首選建議和關鍵理由。
6. 必要時提供穩健、策略或強勢版本。
7. 收束為一件小事、觀察窗口、停止條件和反饋信號。

**拒絕路徑**：若用戶要求實施違法、強迫、跟蹤、詐騙或繞過同意的行為，代理拒絕該操作部分，解釋風險並提供低風險替代。

## 3. 聊天材料分析與即時回覆

1. 判斷素材來自聊天截圖、導出文本、複製對話、用戶轉述、通話、線下互動或混合來源。
2. 只把可確認的原文、發送者、順序、間隔和行為寫入事實；把含義解釋放入推測。
3. 先處理用戶當下情緒，再判斷本輪主要目標是承接、調侃、推進、邀約、澄清還是收線。
4. 用戶只要一句回覆時，第一屏先給一條符合用戶口吻、可直接發送的首選成品。
5. 按對方積極、含糊或拒絕反應給出後續分支；需要練習時每輪只模擬一條回覆並等待用戶接話。

## 4. 主動約會與第一次見面

1. 沒有明確拒絕或不適時，給出至少一個主動聯繫、具體邀約或真實表達動作。
2. 第一次見面建議保持簡潔，覆蓋可交談的地點、共同體驗、具體欣賞和結束時的真實反饋。
3. 根據雙方對恐怖、密閉、運動、噪音和人群的偏好選擇活動，不把“吊橋效應”寫成保證吸引的公式。
4. 肢體互動結合關係與現場適當創造自然、低強度、可退出的機會，並根據對方反應調整。
5. 一次含糊不等於永久退出；沒有明確拒絕時可在合理間隔後換時間或場景再邀請一次。

## 5. 多目標對象比較

1. 為每個對象保留獨立代號與事件記錄。
2. 不用一個對象的MBTI、行為或話術填補另一個對象的信息。
3. 分別評估互惠、可靠、相處體驗、現實可得性和長期風險。
4. 比較“高評分但不可得”和“評分較低但互惠穩定”的真實差異。
5. 保留“暫不選擇任何人”作為合法選項。

## 6. 高情緒強度

1. 先縮小時間範圍，避免連發、報復、突然刪除或其他不可逆動作。
2. 建議暫存消息、離開刺激源或聯繫可信的人陪伴。
3. 在情緒下降後再進入事實分析和策略選擇。
4. 若存在立即自傷或傷人危險，轉入緊急支持，不繼續只給戀愛話術。

## 7. 暴力、控制與危機

1. 識別暴力、性脅迫、跟蹤、財務控制、隱私威脅或詐騙信號。
2. 讀取法律安全與危機轉介文檔。
3. 優先人身安全、可信支持、證據保存和當地專業服務。
4. 不建議用戶在不安全環境中單獨攤牌或以伴侶諮詢替代安全計劃。
5. Skill只提供一般信息；現實緊急情況由當地緊急服務和合格專業人員處理。
