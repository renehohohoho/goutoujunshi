# 知識庫治理

## 分層

| 層級 | 目錄 | 用途 |
| --- | --- | --- |
| 行為規則 | `SKILL.md` | 決定何時詢問、怎樣分析、怎樣輸出和何時切換安全流程 |
| 核心知識 | `references/knowledge/` | 研究、理論、法律、社會、人文與哲學背景 |
| 實用材料 | `references/practical/` | 溝通結構、情緒回應、拒絕、讚美、主動權和表達腳手架 |

經典社交課程只按能力原子轉譯：機制、證據和風險放在 `references/knowledge/`，倫理化練習與輸出結構放在 `references/practical/`。課程原文、逐字稿、媒體、版本清單和研究工作區不進入運行時 Skill。

## 證據等級

1. **較強證據**：元分析、系統綜述、大型縱向研究、正式統計和現行法律文件。
2. **理論框架**：可用於提出問題，但不能直接診斷個體或預測結局。
3. **流行說法**：可幫助理解用戶語言，必須明確證據侷限。
4. **經驗策略**：以適用條件、預期效果、暴露風險和長期代價呈現。

## 包容性要求

- 不把異性戀、婚姻、單偶或生育設為默認終點。
- 分開處理性取向、性別身份與關係結構，不混為同一概念。
- 不根據群體身份推斷性格、忠誠、性行為或關係能力。
- 對所有關係形式使用同一核心標準：知情同意、互惠、尊重、自主、可靠和修復能力。
- 當地區法律對不同人群保護不一致時，明確區分倫理建議與法律現實。

## 更新規則

- 法律、人口、政策、求助渠道和數字平臺信息引用前複核日期與地區。
- 新增研究時優先補充原始或權威來源，不只添加二手總結。
- 新增私人書籍時只沉澱主題索引、短筆記、證據邊界和回答轉化規則；不要把原書全文、長篇摘錄或可替代閱讀的摘要放入運行時 Skill。
- 修改實用話術時保留“適用場景—效果—代價—下一步”結構。
- 新增知識文檔時同步必需文件清單或最低數量，不鎖死精確總數。
- 刪除內容時檢查`SKILL.md`路由和所有相對鏈接。
- 不把真實用戶的私密案例直接沉澱進公開知識庫。
- 默認按當前問題讀取 1–3 份參考；需要證據或風險校準時再增量加載，不批量載入全庫。
