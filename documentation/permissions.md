# 權限邊界

## 運行角色

| 角色 | 能力 | 不能做什麼 |
| --- | --- | --- |
| 用戶 | 提供信息、選擇是否採用建議、決定是否啟用宿主工具 | 不通過本 Skill 自動獲得他人賬號、位置或私密數據 |
| Codex代理 | 讀取 Skill 與按需參考文檔，在任務中生成建議 | 不自動發送消息、不代表用戶作出法律或醫療決定、不繞過工具批准 |
| 倉庫維護者 | 修改公開文件、審查貢獻和發佈版本 | 無權訪問使用者在私人Codex任務中的內容 |
| 貢獻者 | 通過Issue或PR提交公開內容 | 不應提交可識別的真實關係案例或未經授權的私密材料 |

## 資源與操作矩陣

| 資源 | 用戶 | Codex代理 | 維護者／貢獻者 |
| --- | --- | --- | --- |
| `SKILL.md`與參考資料 | 可讀取 | 可讀取 | 通過Git修改公開副本 |
| 當前任務對話 | 可提供和查看 | 僅按宿主上下文訪問 | 默認不可訪問 |
| 用戶本地文件 | 按宿主授權 | 僅在宿主提供工具且用戶授權時訪問 | 不可訪問 |
| 外部消息或賬號 | 用戶自行操作 | 本 Skill 不要求寫權限 | 不可訪問 |
| GitHub倉庫 | 公開讀取 | 無運行時要求 | 按GitHub倉庫權限貢獻 |

## 數據與權限實現

倉庫沒有數據庫、令牌、角色聲明或行級安全機制。運行權限完全由宿主Codex環境和其工具批准系統決定。Skill正文只能約束建議方式，不能提升代理權限，也不能替代程序級訪問控制。
