# 狗頭軍師 · Goutoujunshi

> 把情緒支持、關係科學與可執行策略，裝進一個真正站在用戶一邊的 AI 戀愛軍師。

[![GitHub Stars](https://img.shields.io/github/stars/powerycy/goutoujunshi?style=social)](https://github.com/powerycy/goutoujunshi/stargazers)

如果它讓你在感情裡少一次內耗、多一次清醒，歡迎點亮一個🌟 **Star**。你的支持會讓更多正在關係裡猶豫的人找到它，也會推動知識庫繼續更新。

很多戀愛建議只有兩個答案：“勇敢去追”或“趕緊分手”。狗頭軍師試圖做得更認真一點：先接住用戶的情緒，再把事實、猜測和未知拆開；既分析心動，也計算現實、互惠、風險、機會成本和長期選擇權；最後給出可以真正執行的下一步。

它不只是一個話術庫。它能讀取聊天截圖、導出文本和用戶轉述，區分素材來源與事實邊界；也能把分析落到一句可發送的話、一次具體邀約、第一次見面安排或一段可復盤的對話演練。它是一套覆蓋戀愛全週期、面向多元關係、能夠解釋建議理由的 Codex Skill。

## 它能做什麼

- **主動推進**：在沒有明確拒絕或不適時，幫用戶從等待變成主動聯繫、具體邀約和有反饋分支的下一步。
- **分析聊天材料而不腦補**：識別聊天截圖、導出文本、複製對話、線下轉述和混合素材，只把可見原文、發送者、順序和行為當作事實。
- **設計第一次見面**：根據雙方偏好安排可交談、有共同體驗的約會，提醒用戶具體欣賞、表達真實好感並主動詢問能否再次見面。
- **自然肢體接觸**：提供低強度、可退出、能根據靠近或躲避即時調整的線下互動指導，不把故意觸碰偽裝成意外。
- **真誠表達喜歡**：用具體欣賞、主動聯繫、具體邀約和明確好感讓喜歡變得明顯，不靠故意冷淡製造吸引。
- **首次建立關係檔案**：記錄用戶本人及一個或多個目標對象的 MBTI、主觀綜合評分、關係階段、關鍵事件、雙方投入和現實障礙。
- **先解決情緒，再解決事情**：識別委屈、焦慮、嫉妒、憤怒、執著與失落，避免用戶在情緒峰值做出高代價決定。
- **多人關係獨立分析**：分別維護每個對象的檔案，比較互惠、可靠、吸引、價值觀、現實可行性和長期風險，而不是隻比較“條件分數”。
- **把讀心改成證據**：區分已知事實、合理推測和關鍵未知，重點觀察主動、兌現、投入、邊界和衝突修復。
- **判斷投入失衡與體面退場**：區分節奏差異、暫時壓力和持續失衡，用澄清、事件觀察、降級投入與停止條件保護用戶，不把斷聯包裝成欲擒故縱。
- **場景化聊天與社交校準**：根據網聊、語音、線下場景、關係階段和對方反饋調整鬆弛感、調侃、曖昧與推進節奏。
- **倫理轉譯經典社交體系**：把 Blueprint 內在狀態、自然流、冷讀機制和 Mystery 結構化互動轉成開放假設、真實表達、階段診斷與反饋校準，不保留欺騙和操控實現。
- **給出有梯度的策略**：根據場景提供穩健版、會撩版／策略版和強勢版，附帶發送時機、預期效果、風險代價與後續分支。
- **即時話術與對話演練**：先給一條可發送的首選成品，再按積極、含糊或拒絕反應設計後續分支；也可模擬破冰、調情、邀約、澄清、修復或收線。
- **不迴避現實問題**：共同生活、城市選擇、職業、金錢、家務、育兒、雙方家庭、婚姻制度與退出安排都進入判斷。
- **識別危險而不製造恐慌**：區分普通溝通問題與控制、跟蹤、脅迫、詐騙、家暴等需要安全計劃的情境。

## 不預設你應該愛誰

狗頭軍師支持異性戀、男同性戀、女同性戀、雙性戀、泛性戀、無性戀等不同性取向，也尊重跨性別、非二元性別及其他性別身份。它同樣可以討論單身約會、長期伴侶、婚姻、異地、再婚、跨文化關係，以及建立在知情同意基礎上的非單偶關係。

系統不假設固定的性別角色：男女和多元性別用戶都可以主動，任何人也都可以選擇高主動模式。不套用單一文化或性別的推進腳本，不預設誰該等待、誰該追求。判斷依據始終是具體的人、具體行為、雙方意願和現實條件。

## 安裝

將倉庫克隆到 Codex 的 Skills 目錄：

```bash
git clone https://github.com/powerycy/goutoujunshi.git ~/.codex/skills/goutoujunshi
```

在 Codex 中輸入：

```text
使用 $goutoujunshi 幫我梳理情緒、分析當前關係，並給出下一步建議。
```

首次使用時，它會詢問：

```text
你：MBTI / 綜合評分0–100 / 主要優勢和短板
情緒：目前最難受的點、強度0–10，以及是否有必須馬上回復的消息
對象A：代號 / MBTI / 綜合評分0–100 / 當前關係
對象B（如有）：同上
經過：認識方式、發展時間、關鍵事件、聯繫和投入情況
目標：推進、確認、修復、比較選擇，還是退出
```

不知道的項目可以留空，也可以直接講故事。Skill 會從敘述中整理檔案，並只追問真正會改變建議的信息。

## 一個典型回答如何產生

```text
用戶敘述
  → 情緒落地
  → 建立本人及目標對象檔案
  → 分離事實／推測／未知
  → 檢索當前情境所需知識
  → 比較互惠、現實、風險與機會成本
  → 給出明確首選建議和理由
  → 生成行動、話術、觀察窗口與停止條件
```

## 設計原則

1. **先接住人，再解決事。** 情緒沒有被看見時，最正確的建議也可能無法執行。
2. **行為比標籤可靠。** 不憑MBTI、性別或一次聊天記錄替目標對象讀心。
3. **互惠比追到更重要。** 得到某一個人不是唯一勝利；減少內耗、保留尊嚴與未來選擇權同樣是成功。
4. **策略必須說明代價。** 可以討論撒嬌、推拉、節奏和表達包裝，但同時交代適用條件與長期成本。
5. **同意和退出權不可繞過。** 明確拒絕不是需要破解的障礙。
6. **危險情境先保安全。** 暴力、脅迫、跟蹤、詐騙和自傷風險不能用普通戀愛話術處理。
